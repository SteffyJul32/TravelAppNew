## Usage Notes

- Import Lucide icons in code via `lucide-react` (React) or `lucide-vue-next` (Vue).
- Example: `import { ListChecks, CalendarMinus, BusFront } from 'lucide-react'`
- All Lucide icons accept `size`, `color`, `strokeWidth` props.
- Default icon size in the Travel design system: see `spacing.md` → Icon size tokens.
