## Token Architecture

Tokens follow a three-layer alias chain:

```
Component token  →  Semantic token  →  Primitive token
  (use this)           (maps to)          (raw value)

Action/Primary/
Primary-Default  →  Brand Primary/   →  Green/
  #2D9326            Brand 600           Green 600
```

**Always use component tokens in code** — never hardcode hex values or reference primitives directly. This ensures the UI responds correctly if the design system is updated.

## Icons

The app uses two icon sources:

1. **Custom travel icons** — `Icons`, `Icon button`, `Location icon`, `NavIcons`, `Location` components in the Travel Figma library.
2. **Lucide Icons (Community)** — open-source icon set, imported via `lucide-react`.

```tsx
import { Calendar, MapPin, Bus } from "lucide-react"
```

See `icons.md` for the full list of Lucide icons confirmed in use.

## Updating This Documentation

This folder is generated by the `figma-tokens-to-md` skill. To refresh after a Figma design change:

1. Open Cowork and run the skill with the Figma file URL.
2. Optionally provide the GitHub repo path to commit directly.
3. The skill will overwrite all files in this folder with the latest token values.

To update manually, export variable collections from Figma (Plugins → Tokens or Variables → Export) and run the skill with the exported JSON files attached.
